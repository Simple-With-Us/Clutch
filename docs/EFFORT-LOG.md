- **2026-10-10 — CLUTCH — LANDED — Fleet Recall preset tools dispatch again (board `c304e51f`, PR #92, branch `clutch/recall-preset-execute`).**  Every call to `recall_search`, `recall_stats`, and `recall_contribute` in the fleet-recall agent preset died with `TypeError: userExecute is not a function`; the corpus was reachable the whole time and the failure was in the wrapper.  Two host contracts were wrong in `src/presets/fleet-recall/plugins/fleet-recall-tools.mjs`: `defineTool()` reads the tool body from `execute(args, exec)` and silently ignores a `run` key, so the compiled tools had no body to dispatch, and `ctx.shell.resolve()`/`run()` take one `command` shell string plus `workdir`, while the plugin passed an `args` array and `cwd`, so the resolved spec carried neither the arguments nor the working directory.  The plugin now builds one single-quoted command string, passes `workdir`, forwards `exec.signal`, clamps `limit` to 1..20, and throws on a non-zero exit so a near-duplicate contribute refusal reaches the model as a tool error instead of a success.  Why it survived: a 2026-09-23 effort row records a three-site fix to this same file under the now-retired `~/.dsh/.agent-presets` home, the tracked repo copy kept `run`, and the string-presence assertion in `tests/profiles.test.ts` could not tell the two spellings apart.  New `tests/fleet-recall-tools.test.ts` (11 tests) asserts the `execute` contract, the one-command-plus-workdir spec, quoting, clamping, JSON pretty-printing, abort-signal forwarding, and error propagation, and it drives the definitions through the real installed `defineTool`, which also rejects malformed arguments before the shell is touched.  Validation: `pnpm typecheck` clean, `pnpm test` 247/247, and the exact generated `recall stats --json` and `recall search` commands run through `bash -c` returned the live corpus (60912 points, status green).  The live preset under `~/.clutch/dsh/.agent-presets/fleet-recall/` was refreshed from the fixed file, so sessions started after this entry dispatch.
